# GitHub Setup Instructions

## 🚀 Push to GitHub

### Step 1: Create Repository on GitHub
1. Go to [GitHub.com](https://github.com)
2. Click "New repository" (green button)
3. Repository name: `sentiment-ai`
4. Description: `LSTM-based sentiment analysis with production REST API`
5. Make it **Public** (for resume/portfolio visibility)
6. **DO NOT** initialize with README, .gitignore, or license (we already have these)
7. Click "Create repository"

### Step 2: Push Your Code
Run these commands in your terminal:

```bash
cd "/Users/duncdang/Documents/RepoGH/sentiment-ai"

# Add GitHub as remote origin
git remote add origin https://github.com/YOUR_USERNAME/sentiment-ai.git

# Push to GitHub
git branch -M main
git push -u origin main
```

Replace `YOUR_USERNAME` with your actual GitHub username.

### Step 3: Verify Upload
- Check that all files are visible on GitHub
- Verify the README displays properly with images
- Confirm the repository looks professional
